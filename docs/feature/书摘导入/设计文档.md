# 书摘导入设计文档

更新日期：2026-09-07

## 状态与数据流

`DataImportView` 选择来源后生成统一的 `NoteImportDraftBook` 候选；`NoteImportPreviewViewModel` 在主线程拥有短生命周期预览状态，Repository 负责只读匹配、资料读取、偏好保存和最终事务。视图不直接访问数据库、网络客户端或凭证。

```text
外部来源/解析器
  → NoteImportDraftBook
  → NoteImportPreviewViewModel（选择、筛选、资料和时长决策）
  → NoteImportRepositoryProtocol（匹配、预览、提交）
  → Repository 逐组写入结果
  → 结果 Sheet
```

## 关键设计

### 预览状态隔离

ViewModel 初始化时复制候选为局部预览项。编辑目标书资料、选择内容及选择状态仅存于会话；`commitHandler` 才调用 `commitImportGroup`。这让取消和返回不会触碰数据库。

### 异步竞态与取消

会话在 `@MainActor` 运行；准备阶段遇到取消立即停止。对可变选择集合，使用 revision/ticket 丢弃过期的目标匹配和时长评估结果，避免旧请求反写新选择。提交开始后锁定会话，仅允许完成或结果反馈。

### 事务边界

最终写入按可提交组调用 Repository。每组返回明确结果；失败不伪报整个批次回滚，也不把尚未提交的候选当作已完成。内容为空时禁止隐式创建书籍。

### UI 组件归位

导入筛选、资料编辑、设置与结果 Sheet 是 `DataImport` 业务私有组件，放在 `xmnote/Views/Personal/DataImport/Sheets/`；公共行内说明保留在 `UIComponents/Feedback`。页面私有与复用组件均登记在术语表。
