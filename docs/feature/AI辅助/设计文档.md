# AI 辅助 - 设计文档

## 1. 架构

- 模型：`xmnote/Domain/Models/AIModels.swift`
- 契约：`AIRepositoryProtocol`
- Repository：`xmnote/Data/Repositories/AIRepository.swift`
- 网络：`xmnote/Infra/AI/OpenAICompatibleClient.swift`
- 安全配置：`AIConfigurationStore` + Keychain
- UI：`ContentViewer` 选区菜单、`AIInteractionSheets`、AI 设置页

## 2. 数据流

```text
用户操作 -> ViewModel -> AIRepository
  -> 读取安全配置
  -> OpenAI-compatible 流式/非流式请求
  -> 用户确认
  -> Repository 数据库事务
```

## 3. 一致性保护

- 书摘解读保存时在同一事务重新读取最新 idea，再追加 AI HTML 块。
- 自动标签复用 Note Repository 的标签事务，不复制数据写入逻辑。
- `AsyncThrowingStream` 的生产任务响应取消，网络状态不直接成为 View 的 owner。
- Provider/模型/Prompt 在 Repository 入口统一校验。

## 4. 平台表达

- iOS 使用系统文本选区菜单和 Sheet；Android 使用 TextView ActionMode 与 Compose/BottomSheet。
- 交互不同但 Prompt、供应商、错误分类和最终写入语义对齐。
