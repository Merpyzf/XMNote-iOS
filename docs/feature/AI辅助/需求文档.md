# AI 辅助 - 需求文档

## 1. 目标

- 提供书摘解读、选词释义和自动标签三类 AI 能力。
- 支持用户选择供应商、模型、Prompt 与 API Key，并将完整 AI 配置作为一个本机偏好快照保存和备份。
- 为三类 AI 任务提供独立提示词编辑页，允许分别编辑用户提示词与系统提示词，并在保存前验证变量契约。
- AI 生成结果必须由用户确认后再写回本地数据。

## 2. 规则

- View/ViewModel 不直接调用网络客户端，全部经 `AIRepositoryProtocol`。
- 流式任务可取消；页面离场或用户关闭 Sheet 后停止继续发布。
- 自动标签只写入用户选中的建议；书摘解读追加到最新 idea，不覆盖生成期间的用户编辑。
- 缺少密钥、鉴权失败、余额/权限、限流、服务错误分别给出可理解反馈。
- 三类任务分别维护受控变量白名单；变量只允许插入用户提示词，持久化格式固定为 `${变量名}`。
- 空字段、未知变量、不完整变量和缺少必需变量必须阻止保存与试运行；推荐变量缺失只提示结果风险。
- 恢复当前字段或全部恢复默认只修改页面草稿，必须由用户显式保存后才写入正式配置。
- 单任务保存必须在 Actor 隔离内读取最新配置并只替换对应 Prompt 组合，不能覆盖设置页中的其他未保存草稿。
- 页面存在未保存内容时，系统返回手势、顶部返回和程序化返回必须走同一退出确认。
- “实际发送内容”使用正式请求构建器离线生成；试运行只在用户明确点击后开始，界面和无障碍信息不得展示请求或调用次数。
- 试运行默认正文严格使用《百年孤独》“多年以后……”书摘，并展示书名与作者；用户可直接编辑或从本地书摘 Sheet 搜索选择。
- 本地书摘选择支持正文、想法、书名与作者搜索，按创建时间倒序分页；无可见正文的记录不可用于测试。
- AI 查词必须从原生多行编辑器读取单一连续非空选区；选区无效或因编辑、更换书摘而失效时禁止运行并清除查询词。
- “与应用原始提示词对比”在相同书摘、凭据、模型与生成参数下并发运行当前模板和应用原始模板，仅展示两份结果，不生成第三份总结或评分。
- 试运行结果使用 AI 助手标准 Markdown 组件实时渲染；对照两侧独立维护连接、流式、完成和失败状态，单侧失败不终止另一侧。
- 提示词优化只发送当前字段与调整期望；字段、草稿或请求身份变化后，旧建议不得回写或应用。
- 完整 AI 配置使用 `ai.configuration.v2` 单值写入 `UserDefaults.standard`，避免配置与两家 API Key 分散更新。
- iOS 创建本地、WebDAV 或阿里云备份时，只通过类型化白名单将完整 AI 配置写入 `xmnote_ios_preferences.json`；不得遍历或导出整个 UserDefaults。
- API Key 可明文进入用户主动创建的未加密备份包，但不得进入数据库、Android SharedPreferences 兼容文件、日志、错误文本或分析事件。
- iOS 恢复有效 sidecar 时整组替换 AI 配置；旧版或 Android 备份没有 sidecar 时保留当前设备配置，sidecar 异常不得阻断核心数据库恢复。

## 3. 验收

- 配置、书摘解读、选词释义、标签建议/应用路径可达。
- 三类提示词均可从 AI 配置页进入独立编辑页，切换双字段、插入受控变量、恢复默认并保存。
- 校验问题可定位到对应字段或文本范围；阻断问题存在时不能保存、预览或试运行。
- 未保存退出确认覆盖按钮返回与系统交互式返回，放弃、继续编辑和保存退出语义一致。
- 离线预览与正式请求使用同一变量替换和固定协议；试运行、默认对照及优化任务关闭后不再发布旧结果。
- 默认书摘与元数据正确；本地书摘搜索、分页、选择、取消、禁用空正文及选中勾选行为正确。
- AI 查词只在有效连续文字选区存在时可运行；编辑或更换书摘后旧选区与查询词立即失效。
- 单结果与对照结果都能边生成边渲染标题、粗体、列表、表格和链接；对照选择器与水平滑动同步，单侧失败保留另一侧结果。
- 试运行页面不存在“内置样例”“最近书摘”、请求次数或原始 Markdown 符号泄漏。
- 取消后无陈旧文本回写；并发编辑不会被 AI 结果覆盖。
- 网络或配置失败保留当前内容现场。
- 本地、WebDAV 与阿里云备份包含相同的 iOS 白名单 sidecar，并可在另一台 iOS 设备整组恢复 AI 配置。
