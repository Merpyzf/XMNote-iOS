# AI 辅助 - 需求文档

## 1. 目标

- 提供书摘解读、选词释义和自动标签三类 AI 能力。
- 支持用户选择供应商、模型、Prompt 与 API Key，并将完整 AI 配置作为一个本机偏好快照保存和备份。
- AI 生成结果必须由用户确认后再写回本地数据。

## 2. 规则

- View/ViewModel 不直接调用网络客户端，全部经 `AIRepositoryProtocol`。
- 流式任务可取消；页面离场或用户关闭 Sheet 后停止继续发布。
- 自动标签只写入用户选中的建议；书摘解读追加到最新 idea，不覆盖生成期间的用户编辑。
- 缺少密钥、鉴权失败、余额/权限、限流、服务错误分别给出可理解反馈。
- 完整 AI 配置使用 `ai.configuration.v2` 单值写入 `UserDefaults.standard`，避免配置与两家 API Key 分散更新。
- iOS 创建本地、WebDAV 或阿里云备份时，只通过类型化白名单将完整 AI 配置写入 `xmnote_ios_preferences.json`；不得遍历或导出整个 UserDefaults。
- API Key 可明文进入用户主动创建的未加密备份包，但不得进入数据库、Android SharedPreferences 兼容文件、日志、错误文本或分析事件。
- iOS 恢复有效 sidecar 时整组替换 AI 配置；旧版或 Android 备份没有 sidecar 时保留当前设备配置，sidecar 异常不得阻断核心数据库恢复。

## 3. 验收

- 配置、书摘解读、选词释义、标签建议/应用路径可达。
- 取消后无陈旧文本回写；并发编辑不会被 AI 结果覆盖。
- 网络或配置失败保留当前内容现场。
- 本地、WebDAV 与阿里云备份包含相同的 iOS 白名单 sidecar，并可在另一台 iOS 设备整组恢复 AI 配置。
