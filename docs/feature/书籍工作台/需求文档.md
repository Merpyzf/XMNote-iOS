# 书籍工作台需求文档

## 名称与定位

- 页面统一名称：**书籍工作台**。
- 英文口径：**Book Workspace**。
- 当前 iOS 入口类型继续使用 `BookDetailView`，这是代码兼容名称，不再作为产品页面名称。
- Android 对应页面为 `NoteManagerActivity`。双端类名不同，但都承担“围绕单本书集中浏览资料与管理目录、书摘、相关内容、书评”的职责。
- 单独描述某个内容域时，使用“目录页”“书摘域”“相关域”“书评域”；只有指代整个页面时使用“书籍工作台”。

## 用户目标

- 进入一本书后，先确认书籍身份、阅读状态和阅读概览。
- 在同一页面内切换目录、书摘、相关内容与书评，不丢失各域的浏览位置。
- 快速搜索、筛选、排序或创建当前内容域的内容。
- 从头部进入阅读详情、阅读状态和书籍编辑等单书操作。

## 本轮交付范围

### 1. 共享书籍信息头部

- 页面顶部唯一展示一个可随纵向滚动收起的书籍信息头部。
- 头部支持展示：
  - 书名
  - 作者
  - 出版社
  - 出版日期
  - 封面
  - 阅读状态徽标
  - 累计阅读时长
  - 评分
  - 当前书签
  - 阅读进度
- 出版社和出版日期沿用 iOS 的同一行组合表达，以 ` · ` 分隔。
- 出版日期为空或为 Android 占位值 `1970-01-01` 时不显示。
- 阅读状态需要保留多刷语义：
  - 当前已读且累计读完次数大于 1 时显示“2 刷”等文案。
  - 已有读完记录且当前在读时显示“2 刷中”等文案。
  - 徽标颜色由当前阅读状态决定，不由格式化后的文案反推。
- 阅读指标遵循有效值显示：
  - 阅读时长大于 0 才显示，并保留完整有效单位组合。
  - 评分大于 0 才显示。
  - 书签和阅读进度独立判断，可同时出现。
  - 四类指标均无有效值时，整个指标区隐藏。
- 书摘数量不在头部重复展示；内容域 Tab 仍可展示数量。
- 作者与译者的组合文案属于独立对齐事项，本轮不宣告完成。

### 2. 四个内容域

- 内容域固定为“目录、书摘、相关、书评”，顺序与 Android 一致。
- 默认进入“书摘”域。
- 四个内容域的滚动容器常驻，切换后恢复各自滚动位置。
- 每个域拥有独立的搜索、筛选或排序语义；分页拖动过程中不提前切换工具栏业务语义，页面落定后再提交选中态。
- 目录支持层级展开与收起；书摘按章节分组；相关内容按分类组织；书评支持时间排序。

### 3. 共享滚动与吸顶行为

- 书籍头部和 Tab 是页面唯一实例，不随四个内容域重复创建。
- 当前内容域纵向滚动时，头部连续收起，Tab 停留在内容视口顶部。
- 书摘章节标题在 Tab 下方保持原生吸顶和下一章节推离行为。
- 横向切换时，共享头部位置由相邻内容域的真实滚动量插值，不把连续滚动值写回 SwiftUI 页面状态。

### 4. Tab 指示线

- 页面首次布局、异步主题取色、动态字体变化和横竖屏切换时，指示线必须在几何有效后立即落位。
- 任意时刻只允许存在一个视觉指示线实例。
- 主题变化只能动画背景颜色，不得为整个 Tab 容器创建包含标题和指示线的转场快照。
- 指示线位移只由用户点击 Tab 或横向分页的连续位置驱动。
- Reduce Motion 开启时，分页校准和 Tab 可见区域调整立即完成。

### 5. 主题与可访问性

- 主题色由封面取色派生，但正文画布和卡片表面必须保持不透明和足够文字对比度。
- 主题变化保留轻微颜色过渡，不驱动标题、指示线或布局动画。
- 支持动态字体、辅助功能字号、横竖屏和 Reduce Motion。
- 封面统一使用 `XMBookCover`，页面不新增另一套封面渲染实现。

## 数据与架构边界

- 所有书籍资料和四域内容必须经 `BookDetailRepositoryProtocol` 获取，ViewModel 不直接访问数据库。
- 详情查询继续遵循 Android 数据库口径，不修改 schema、migration 或写入逻辑。
- `book_read_status_record` 的读完次数只统计 `is_deleted = 0`、目标 `book_id` 且 `read_status_id = 3` 的记录。
- 展示派生任务允许取消；新输入到达后，旧 revision 不得覆盖最新快照。
- 页面私有 UIKit/SwiftUI 混合组件继续位于 `xmnote/Views/Book/Components/`，不提升为跨模块公共组件。

## 非目标

- 不要求 iOS 与 Android 像素级同构。
- 不重做书籍编辑、阅读计时、内容查看器或数据库写入链路。
- 不在本轮完成作者与译者的组合展示。
- 不把书籍工作台私有 Pager、Scope Bar 或书摘卡片抽到 `UIComponents`。

## 验收标准

- 用户和文档统一称整个页面为“书籍工作台”。
- 头部有效书籍信息项与 Android 对齐，书摘数量和作者/译者按已声明边界处理。
- 冷启动、返回后再次进入、主题异步变化全过程只出现一条 Tab 指示线。
- 点击 Tab 和横向滑动时指示线连续跟随，落定位置正确。
- 四域分别保留滚动位置，头部、Tab、章节吸顶和返回手势无回归。
- 动态字体、横竖屏和 Reduce Motion 下页面可读且没有错误中间位置。
