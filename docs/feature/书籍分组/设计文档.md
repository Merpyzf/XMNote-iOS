# 书籍分组 - 设计文档

## 1. 分层

- 页面：`xmnote/Views/Personal/BookGroupManagementView.swift`
- 行组件：`xmnote/Views/Personal/Components/BookGroupManagementRowView.swift`
- 状态：`xmnote/ViewModels/Personal/BookGroupManagementViewModel.swift`
- Repository：`xmnote/Data/Repositories/BookGroupManagementRepository.swift`
- 模型：`xmnote/Domain/Models/BookGroupManagementModels.swift`
- 组合封面：`xmnote/Views/Personal/Components/XMBookGroupCover.swift`

## 2. 事务

- 观察查询同时返回分组元信息、书籍数量和最多四张封面。
- 新建/重命名在数据库层判重。
- 删除先读取目标分组及组内书籍，再按用户选择重新计算书籍/分组 order，最后软删除分组。
- 排序校验 ID 集合与当前有效集合一致，拒绝缺失、重复或跨作用域写入。

## 3. UI

- 浏览态提供新增、重命名和进入整理模式。
- 整理态使用原生移动能力和批量选择；成功不弹冗余提示。
- `XMBookGroupCover` 负责封面布局、占位和边框，不由页面手写组合。
