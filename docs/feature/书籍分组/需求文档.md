# 书籍分组 - 需求文档

## 1. 目标

- 在“我的”中提供书籍分组管理，支持新建、重命名、多选删除和手动排序。
- 删除分组时由用户决定组内书籍移到分组前或分组后，不能隐式丢失书籍。
- 书架分组封面统一使用组合封面组件表达真实成员书籍。

## 2. 规则

- 名称去除首尾空白后不能为空，且与有效分组不重名。
- 排序提交完整分组 ID 顺序，并在单事务写回连续 order。
- 批量删除与组内书籍重新安置在同一事务完成。
- 写入中禁用重复操作；失败保留原列表或回滚本地排序预览。

## 3. 验收

- 新建、重命名、批量删除、排序可用。
- 删除前能选择书籍安置方向。
- 组合封面在 0/1/2/3/4+ 本书与深浅色模式下稳定。
