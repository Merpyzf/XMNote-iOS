# 书摘导出需求文档

更新日期：2026-09-07

## 目标

让用户从书架或单书工作台选择导出范围，并以本地文件或已认证的远端目标安全导出书籍、书摘与想法。导出过程需显示真实进度、可取消、可区分逐项失败，且认证凭据不得进入视图状态或日志。

## 范围

- 支持 CSV、纯文本、Markdown、PDF 等本地文件导出，并通过系统文件选择器交付文件。
- 支持 Notion、OneNote、Obsidian 及桌面网页目标的设置、认证和任务编排。
- 支持单书和多书选择，导出前验证目标需要的认证或设置。
- 导出 PDF 使用随应用注册的思源宋体资源及许可证；保留字体注册和许可文本。
- 提供与 Android 导出样例对应的迁移合同 fixture。

## 非目标

- 不在本次范围执行真实远端写入或授权账号验证。
- 不保证所有 Android 第三方目标在 iOS 已具备同一 API 覆盖；缺失目标需明确登记为未对齐，不以空入口代替。
- 不提交账户令牌、个人设置或导出产物。

## 验收口径

1. 导出路由从最终书架/详情结构可达，且单书与批量选择范围一致。
2. 所有目标的前置配置在执行前校验；令牌由专门服务保存与获取。
3. 取消不会继续推进未开始的导出步骤；失败结果能定位到目标或书籍。
4. 本地导出使用系统 picker，回调只完成一次。
5. 许可证、字体、工程注册和依赖锁一致存在。
