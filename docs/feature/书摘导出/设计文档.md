# 书摘导出设计文档

更新日期：2026-09-07

## 结构

导出路由负责把书籍范围送入 `ExportView`；`ExportViewModel` 是主线程状态 owner，维护目标选择、认证提示、执行进度与取消；`ExportRepositoryProtocol` 隔离数据读取和导出准备。生成器与认证服务各自保持单一职责。

```text
书架/单书入口
  → ExportRoute / ExportView
  → ExportViewModel
  → ExportRepositoryProtocol
  ├─ 本地生成器（CSV / Markdown / TXT / PDF）→ ExportDocumentPicker
  └─ 远端生成器（Notion / OneNote / Obsidian / Desktop Web）→ 认证服务
```

## 并发与凭据

ViewModel 的导出任务在主线程协调，耗时读写交给 Repository/Service。取消传播到尚未完成的任务，UI 只接收当前任务的结果。Notion 使用系统 Web 认证会话并校验回调 state；OneNote 通过 MSAL 获取交互式或静默令牌。令牌不放入 SwiftUI View、导出文件名或测试样例。

## 本地文件交付

`ExportDocumentPicker` 位于 `Views/Export/Components`，是页面私有的 UIKit 桥接器。它以 `UIDocumentPickerViewController(forExporting:asCopy:)` 导出已生成文件，并通过单一完成回调通知页面。组件不提升为公共 UIComponents，避免把单一工作流的桥接误当作跨模块能力。

## 依赖与资源

MSAL 版本由 SwiftPM 锁定；`xmnote-Info.plist`、工程配置和应用生命周期共同注册认证回调。PDF 字体资源与 `SourceHanSerif-LICENSE.txt` 必须成对保留，不能只引入二进制字体。
