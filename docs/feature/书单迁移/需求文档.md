# 书单迁移需求文档

更新日期：2026-06-27

## 背景

书单模块是 Android -> iOS 迁移中书籍域的第二主入口，承载手动书单、年度书单、书单内书籍关系、微信读书书单导入、书单分享与从书架批量加入书单。Android 端已形成 `collection` 与 `collection_book` 两张表的稳定语义：手动书单由用户维护，年度书单由读完记录自动同步，远端或导入书籍可作为 `book.is_deleted = 1` 的占位书留在书单中。

iOS 端本轮迁移目标不是逐行复刻 Android Activity/Fragment，而是在保持数据库与业务意图一致的前提下，用 SwiftUI、Repository 和 iOS 原生 Sheet/分享面板完成等价能力。

## 目标

- 开放书籍页二级入口中的 `书单` Tab，并支持手动书单与年度书单分组浏览。
- 手动书单支持创建、编辑、删除、排序、书单内加书、移出书籍、书籍排序、收藏理由与元信息编辑。
- 年度书单由阅读状态同步维护成员，允许编辑年度说明与单本年度点评，不允许手动改标题、成员或排序。
- 支持本地书、在线搜索结果、手动创建结果和微信读书导入占位书进入书单。
- 支持占位书恢复到书架，保留原书单关系。
- 支持微信读书书单链接粘贴导入和系统分享导入。
- 支持书单分享图生成并调用系统分享。
- 从书架批量整理入口可将选中书籍加入手动书单。
- 所有本地与网络数据访问经 Repository；ViewModel 不直连数据库或网络客户端。

## 非目标

- 本轮不实现 Android 详情页的 `批量导出书籍` 真实导出能力；该项在对齐文档中登记为未对齐缺口。
- 不新增与 Android 不一致的书单数据库 schema，不改变 `collection` / `collection_book` 字段含义。
- 不把书单私有视觉组件迁入 `xmnote/UIComponents`。
- 不复刻 Android 的 Toast、Activity 栈和 RecyclerView 交互外观。
- 不把微信读书导入扩展成通用网页书单抓取器。

## 功能需求

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| FR-01 | 书单 Tab 可从书籍首页进入。 | 顶部二级切换展示 `书籍` / `书单`；切到书单时显示书单列表和书单专属操作。 |
| FR-02 | 书单列表支持手动/年度分组。 | 手动书单按 `order` 升序；年度书单按年份倒序且空年度不展示；最近选择分组可恢复。 |
| FR-03 | 手动书单可创建、编辑、删除和排序。 | 表单保存、删除确认、拖拽排序均经 Repository 写入；年度书单不开放这些结构操作。 |
| FR-04 | 书单详情展示书单信息和成员书籍。 | 手动书单按 relation order 展示；年度书单按读完时间倒序展示；显示书籍封面、标题、作者、统计和 relation 文本。 |
| FR-05 | 手动书单可添加本地书、在线书与手动创建书。 | 选书器支持本地+在线组合、多选、内联手动创建；保存时去重并写入 relation。 |
| FR-06 | 占位书可展示、编辑和恢复。 | `book.is_deleted = 1` 的书在手动书单中可见；可编辑基础信息；点击恢复后进入书架并切到在读状态。 |
| FR-07 | relation 文本按书单类型呈现。 | 手动书单文案为 `收藏理由`；年度书单文案为 `年度点评`；两者共用 `collection_book.recommend`。 |
| FR-08 | 年度书单说明可编辑。 | 只更新年度 `collection.desc`；不允许修改年度标题、年份、成员或排序。 |
| FR-09 | 微信读书书单可导入。 | 应用内粘贴链接先展示预览再保存；系统分享入口可自动导入；解析失败不写入半成品。 |
| FR-10 | 书单分享图可生成。 | 详情页更多菜单提供 `分享书单`；空书单给出反馈；成功后打开系统分享面板。 |
| FR-11 | 书架批量加入书单可用。 | 书架整理态可选择手动书单或新建书单，再把选中书籍加入目标书单，重复关系不重复插入。 |
| FR-12 | 书单批量导出书籍需补齐。 | Android 已有该能力；iOS 当前仅登记 TODO，后续必须实现当前书单范围锁定的导出入口。 |

## 数据要求

- iOS `CollectionRecord` 与 Android `CollectionEntity` 对齐：`title`、`desc`、`order`、`is_annual`、`year` 与基础同步字段保持一致。
- iOS `CollectionBookRecord` 与 Android `CollectionBookEntity` 对齐：`collection_id`、`book_id`、`recommend`、`order` 与基础同步字段保持一致。
- 手动书单详情读取不排除软删除书籍，以保留占位书；年度书单详情必须过滤 `book.is_deleted = 0`。
- 占位书入库保持 `book.is_deleted = 1`；恢复时改为有效书籍，并按 Android `addBookToRead` 语义写入在读状态。
- 微信读书导入在保存前只保留内存预览；确认后在单个 Repository 事务中创建或复用书单，并写入占位书与 relation。
- 书架批量加入书单的关系排序沿用 Android `Int.MAX_VALUE` 追加语义。

## 交互要求

- 读取加载继续使用 `LoadingGate` / `LoadingStateView` / `LoadPhaseHost`，不新增裸 `ProgressView` 主加载态。
- 写操作必须即时显示反馈，并在执行中禁用重复触发。
- 删除书单、移出书籍等破坏性确认继续使用 `XMSystemAlert`。
- 书籍封面统一使用 `XMBookCover`。
- 生产文本使用 `AppTypography` 与语义色。
- 书单详情底部高频操作只保留 `添加书籍`；对象级低频操作放到顶部更多菜单。

## 验收清单

- 创建手动书单后列表即时刷新，并位于手动书单列表前部。
- 编辑手动书单标题/简介后，详情和列表都展示最新内容。
- 删除手动书单后，书单本体与关系均软删除，详情页返回。
- 手动书单排序和书单内书籍排序可保存。
- 年度书单在读完状态变化后自动创建、补齐或移除关系。
- 年度说明、年度点评、收藏理由三者文案不混淆。
- 从本地书、在线结果、手动创建结果添加到书单均可用。
- 微信读书链接导入预览可确认保存，系统分享导入可进入书单详情。
- 占位书可编辑元信息、选择封面并恢复到书架。
- 书单分享图成功后打开系统分享；空书单给出不可分享反馈。
- 书架批量加入书单不重复写入已有关系。
- 批量导出书籍仍显示为未完成缺口，不得在 UI 中伪装成可用能力。
