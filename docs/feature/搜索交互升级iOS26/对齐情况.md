# 搜索交互升级 iOS26 iOS ↔ Android 对齐情况

评估日期：2026-06-11

## 功能点清单

1. 搜索入口激活机制
- 功能点：点击底部搜索入口后的首屏交互。
- iOS 行为：使用 `role: .search + .tabViewSearchActivation(.searchTabSelection) + .searchable` 维持系统搜索体验，但根级搜索宿主只在搜索 Tab 激活时生效，避免污染其他导航栈。
- Android 行为：通过 `SearchActivity` 进入独立搜索页面，页面内 `searchField` 直接聚焦并执行搜索。
- 对齐状态：有意差异。
- 双端代码证据：
  - iOS：`xmnote/Views/MainTabView.swift:159`、`xmnote/Views/MainTabView.swift:185`、`xmnote/Views/MainTabView.swift:186`、`xmnote/Views/MainTabView.swift:428`
  - Android：`/Users/wangke/Workspace/AndroidProjects/XMNote/app/src/main/java/com/merpyzf/xmnote/ui/search/activity/SearchActivity.kt:36`、`/Users/wangke/Workspace/AndroidProjects/XMNote/app/src/main/java/com/merpyzf/xmnote/ui/search/activity/SearchActivity.kt:79`
- 评估结论：功能优化（iOS 原生化表达）。
- Android 反向建议：
  - 是否吸收：可选吸收。
  - 建议优先级：低。
  - 风险：中（涉及导航语义和系统搜索入口重构）。

2. 搜索输入控件位置
- 功能点：输入框在系统层还是页面层。
- iOS 行为：`SearchView` 不再自带输入框，输入来自系统 `searchable` 绑定。
- Android 行为：`SearchActivity` 页面内持有 `searchField`，并绑定 `onSearch` 回调。
- 对齐状态：有意差异。
- 双端代码证据：
  - iOS：`xmnote/Views/MainTabView.swift:453`、`xmnote/Views/MainTabView.swift:460`、`xmnote/Views/MainTabView.swift:489`
  - Android：`/Users/wangke/Workspace/AndroidProjects/XMNote/app/src/main/java/com/merpyzf/xmnote/ui/search/activity/SearchActivity.kt:66`、`/Users/wangke/Workspace/AndroidProjects/XMNote/app/src/main/java/com/merpyzf/xmnote/ui/search/activity/SearchActivity.kt:79`
- 评估结论：功能优化（遵循 iOS 26 搜索交互）。
- Android 反向建议：
  - 是否吸收：按平台策略决定，不强制。
  - 建议优先级：低。
  - 风险：中（会改变 Android 用户既有输入心智）。

3. 结果容器完整度
- 功能点：搜索结果是否具备多类型分栏与真实结果承载。
- iOS 行为：当前 `SearchView` 仍以占位态文案为主，未完成分类结果分栏承载。
- Android 行为：`SearchActivity` 已接入 `ViewPager + TabLayout`，按结果数量动态生成结果页。
- 对齐状态：未对齐。
- 双端代码证据：
  - iOS：`xmnote/Views/MainTabView.swift:480-514`
  - Android：`/Users/wangke/Workspace/AndroidProjects/XMNote/app/src/main/java/com/merpyzf/xmnote/ui/search/activity/SearchActivity.kt:134`、`/Users/wangke/Workspace/AndroidProjects/XMNote/app/src/main/java/com/merpyzf/xmnote/ui/search/activity/SearchActivity.kt:178`
- 评估结论：设计倒退（功能尚未补齐）。
- Android 反向建议：
  - 是否吸收：不建议吸收 iOS 当前占位实现。
  - 建议优先级：高（iOS 需补齐）。
  - 风险：高（直接影响搜索可用性与留存）。

4. 搜索入口上下文注入能力
- 功能点：不同业务入口传入不同搜索域与默认选中项。
- iOS 行为：当前以统一 Tab 搜索入口为主，尚无按入口注入 `searchItems` 的能力。
- Android 行为：`SearchActivity.start(...)` 支持按入口构造 `searchItems` 与默认选中项。
- 对齐状态：未对齐。
- 双端代码证据：
  - iOS：`xmnote/Views/MainTabView.swift:159`
  - Android：`/Users/wangke/Workspace/AndroidProjects/XMNote/app/src/main/java/com/merpyzf/xmnote/ui/search/activity/SearchActivity.kt:232`、`/Users/wangke/Workspace/AndroidProjects/XMNote/app/src/main/java/com/merpyzf/xmnote/ui/search/activity/SearchActivity.kt:292`
- 评估结论：设计倒退（业务入口语义丢失）。
- Android 反向建议：
  - 是否吸收：不建议。
  - 建议优先级：中高（iOS 应补入口上下文能力）。
  - 风险：中（影响不同场景下的搜索效率与命中率）。

5. 搜索历史展示与管理
- 功能点：空查询态最近搜索词展示、选择、单删与清空。
- iOS 行为：全局搜索通过 `XMSearchHistorySection` 展示最近搜索词，支持浏览态选择、编辑态单删、清空入口与 chip 操作槽动效；最近搜索词由 `GlobalSearchViewModel` 和 `GlobalSearchRepository` 持久化管理。
- Android 行为：`SearchActivity` 页面内搜索框直接提交关键词，`SearchViewModel` 只保存当前 `keyword`、结果页和分类状态，没有持久化最近搜索词列表或历史管理 UI。
- 对齐状态：有意差异。
- 双端代码证据：
  - iOS：`xmnote/Views/Search/GlobalSearchView.swift:674`、`xmnote/UIComponents/Foundation/XMSearchHistorySection.swift:43`、`xmnote/UIComponents/Foundation/XMSearchHistorySection.swift:271`
  - Android：`/Users/wangke/Workspace/AndroidProjects/XMNote/app/src/main/java/com/merpyzf/xmnote/ui/search/activity/SearchActivity.kt:80`、`/Users/wangke/Workspace/AndroidProjects/XMNote/app/src/main/java/com/merpyzf/xmnote/viewmodel/search/SearchViewModel.kt:25`
- 评估结论：功能优化（iOS 补齐最近搜索效率入口）。
- Android 反向建议：
  - 是否吸收：可选吸收。
  - 建议优先级：中。
  - 风险：中（需要新增历史存储、隐私清理入口和空查询态管理）。

6. 搜索历史清空确认时序
- 功能点：清空全部最近搜索词前的确认弹窗与底层上下文稳定性。
- iOS 行为：点击“清空”后先释放系统搜索框焦点，再展示 `XMSystemAlertController`；确认前不修改 `recentQueries`、不退出编辑态、不重排历史 chip；destructive 确认后才清空并退出历史管理态。
- Android 行为：当前全局搜索无最近搜索词管理，因此不存在对应清空确认链路。
- 对齐状态：有意差异。
- 双端代码证据：
  - iOS：`xmnote/Views/MainTabView.swift:228`、`xmnote/Views/Search/GlobalSearchView.swift:172`、`xmnote/Views/Search/GlobalSearchView.swift:190`、`xmnote/Views/Search/GlobalSearchView.swift:198`
  - Android：`/Users/wangke/Workspace/AndroidProjects/XMNote/app/src/main/java/com/merpyzf/xmnote/ui/search/activity/SearchActivity.kt:80`、`/Users/wangke/Workspace/AndroidProjects/XMNote/app/src/main/java/com/merpyzf/xmnote/viewmodel/search/SearchViewModel.kt:21`
- 评估结论：功能优化（符合 iOS 决策暂停点与键盘焦点模型）。
- Android 反向建议：
  - 是否吸收：仅在 Android 新增最近搜索历史后再评估。
  - 建议优先级：低。
  - 风险：低（当前 Android 无同类入口，直接套用没有价值）。
