# 首页书架管理需求文档

更新日期：2026-06-07

## 背景

首页书架管理是 Android -> iOS 迁移中书籍域的主入口，承载默认书架、二级维度列表、书籍录入、搜索添加、批量整理与阅读状态写入。2026-06-03 反向扫描发现 iOS 主干骨架已接近 Android，但阅读状态副作用、编辑页状态写入、新书排序、搜索来源设置、网格排序展示和占位入口仍存在对齐风险。

## 目标

- 数据库写入语义与 Android 保持一致，覆盖阅读状态历史、当前状态、读完进度、评分、年度书单关系与新书排序。
- 首页和二级列表补齐用户可见的 P1 行为差异，包括搜索来源生产列表、页数设置和网格排序辅助信息。
- 交互采用 iOS 原生表达：写操作有即时反馈，破坏性操作有系统确认，未完成跨模块能力不暴露假入口。

## 非目标

- 本轮不实现完整书单、导出、阅读详情、阅读计时、阅读记录、章节目录和补录阅读模块。
- 本轮不新增 Android 式 Toast 外观，不复刻 Activity/Fragment 跳转形态。
- 本轮不改变数据库 schema 和 migration 顺序；仅修正 Repository 写入条件与副作用。

## 功能需求

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| FR-01 | 阅读状态写入统一经 Data 层 helper。 | 批量设置、编辑页保存、新书初始状态使用同一规则；同状态更新最新历史，不同状态插入历史。 |
| FR-02 | 读完状态副作用完整。 | 读完推进阅读进度到终点；评分允许 0，`nil` 按 0 写入，所有评分 clamp 到 `0...50`。 |
| FR-03 | 年度书单同步与 Android 对齐。 | 读完年份来自有效历史和 `book` 当前快照；缺失年度书单自动创建，失效关系软删。 |
| FR-04 | 新书排序按用户设置。 | `newAddBookPosition=0` 时放目标作用域开头，`1` 时放末尾；默认值为开头。 |
| FR-05 | 搜索来源生产入口稳定。 | 生产入口不展示番茄；文曲、豆瓣、起点、纵横、晋江、长佩按固定顺序展示。 |
| FR-06 | 搜索页数设置仅展示有效来源。 | 豆瓣默认 1 页，起点和长佩默认 2 页；服务层按页请求并对结果去重。 |
| FR-07 | 网格排序提供上下文辅助信息。 | 网格在出版时间、阅读时长、读完时间、阅读进度、创建时间、修改时间、评分排序下显示一行辅助文案，并纳入无障碍朗读。 |
| FR-08 | 未完成跨模块入口隐藏。 | 长按菜单和底部批量工具栏不显示只能提示“迁移后开放”的书单、导出、阅读详情和计时入口。 |
| FR-09 | 写操作反馈符合 iOS HIG。 | 写操作立即进入 processing 并禁用重复触发；成功短驻留；警告/错误保留到下一次操作；中心确认继续使用 `XMSystemAlert`。 |
| FR-10 | 书籍/书单二级页切换硬切。 | 点击顶部 `书籍` / `书单` 时，顶部选中态、内容页和保活激活同帧切换；不得出现顶部文字滞后、内容叠影、横向滑入、淡入淡出或卡片进场动画。 |

## 交互要求

- 批量操作优先使用底部工具栏和业务 Sheet 承载，不新增中心 `.alert` 实现。
- 删除、重命名等高风险操作继续使用 `XMSystemAlert`，破坏性按钮使用系统 destructive 语义。
- Android Toast 只作为业务意图参考；iOS 采用上下文内反馈条、忙态禁用和错误保留。
- 结构性 UI 变化保持 `.snappy`、`.smooth` 或系统集合视图动画；辅助文案不能挤压封面和书名稳定尺寸。
- 顶部 `书籍` / `书单` 二级页切换属于导航硬切，不触发页面级过渡动画；书籍页内部整理模式、搜索 drawer、批量工具栏等业务动画继续保留。

## 数据要求

- 所有本地写入必须经 Repository，不允许 ViewModel 直接访问 GRDB。
- 原生 SQL 必须保留语义注释，说明涉及表、过滤条件、时间字段和副作用。
- 年度书单创建字段沿用 Android 默认语义：标题 `"{year} 年阅读书单"`、`is_annual=1`、`year=year`、`order=year`。
- 不属于读完年份的年度书单关系只软删 `collection_book.is_deleted = 1`，不额外写 `updated_date`。

## 验收清单

- 同一本书同状态更新时间只更新最新历史；不同状态插入新历史。
- 读完评分 0 可保存，`book.score=0`，进度推进到终点。
- 编辑页改为读完与批量改为读完落库结果一致。
- 新增读完书进入对应年度书单；改出读完后软删年度关系。
- 新书默认放开头，设置末尾后放末尾；默认书架和分组分别验证。
- 搜索来源不显示番茄；页数设置只显示服务层实际消费页数的来源。
- 网格切换排序时辅助信息出现且不挤压封面/标题。
- 未完成跨模块能力不出现可点击占位入口。
- 写操作有即时反馈、忙态禁用、成功短驻留和错误保留。
- 连续点击顶部 `书单 -> 书籍 -> 书单 -> 书籍` 时，顶部选中态与内容同帧切换，已激活页面保活且不产生淡入、叠影或列表卡片进场。
