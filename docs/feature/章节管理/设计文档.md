# 章节管理 - 设计文档

## 1. 分层

- 页面：`xmnote/Views/Book/ChapterManagerView.swift`
- Sheet：`xmnote/Views/Book/Sheets/ChapterManagementSheets.swift`
- 状态：`xmnote/ViewModels/Book/ChapterManagerViewModel.swift`
- 契约：`xmnote/Domain/Repositories/ChapterManagementRepositoryProtocol.swift`
- 实现：`xmnote/Data/Repositories/ChapterManagementRepository.swift`

## 2. 数据约束

- 所有查询限定 `book_id` 且过滤 `is_deleted`。
- 写入使用 Android 毫秒时间戳；GRDB 事务包住结构更新、书摘迁移和排序修复。
- 移动前读取真实父子树并校验环；删除前扩展后代集合。
- 同级 `chapter_order` 使用连续顺序写回，保证 Android/iOS 读取一致。

## 3. 交互

- 管理页属于当前书籍浏览路径，使用 `NavigationStack + BookRoute.chapterManager`。
- 标题编辑与删除确认使用 `XMSystemAlert`。
- 批量录入、移动、排序和远端选择使用业务 Sheet。
- 写入任务由 ViewModel 持有，页面离场取消未完成的异步准备任务。

## 4. 验证

- 构建通过；手工检查两级结构、跨父级移动、同级排序和删除后的书摘归属。
