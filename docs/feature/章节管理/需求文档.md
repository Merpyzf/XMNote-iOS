# 章节管理 - 需求文档

## 1. 目标

- 在单书上下文管理两级目录，覆盖新增、重命名、星标、移动、缩进/减少缩进、同级排序、批量录入、远端目录选择和删除。
- 章节结构写入必须通过 Repository 单事务完成，并保持书摘归属可解释。

## 2. 规则

- 章节只允许当前书内移动；禁止移动到自身或后代。
- 同级排序提交完整 ID 顺序，不能只写单个位置。
- 删除前明确“书摘移到父级/未指定章节”或级联处理结果。
- 写操作即时显示反馈并阻止重复触发；成功以列表结构变化表达。
- OCR、手工批量和远端同步只产生草稿，用户确认后才写库。

## 3. 验收

- 新增、重命名、移动、排序、星标和删除均可用。
- 失败时保留原结构并展示原因。
- 单书工作台可进入管理页，管理后目录与书摘分组实时刷新。
