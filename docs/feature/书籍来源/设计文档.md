# 书籍来源 - 设计文档

## 1. 分层

- 页面：`xmnote/Views/Personal/SourceManagementView.swift`
- 列表：`xmnote/Views/Personal/Components/SourceManagementListView.swift`
- 状态：`xmnote/ViewModels/Personal/SourceManagementViewModel.swift`
- Repository：`xmnote/Data/Repositories/SourceManagementRepository.swift`
- 模型：`xmnote/Domain/Models/SourceManagementModels.swift`

## 2. 数据策略

- 观察快照一次返回“我的来源”和“默认来源”，并统计每个来源的有效书籍数。
- 创建与重命名在数据库层判重，使用 Android 毫秒时间戳。
- 删除事务先把书籍 `source_id` 更新为未知来源，再软删除自定义来源。
- 排序校验目标 IDs 与对应 scope 的完整集合一致，写回连续 order。

## 3. UI 与并发

- `XMInlineTabBar` 在两个 scope 间切换；每个 scope 保留独立选择与本地排序草稿。
- ViewModel 作为写入门闩和错误 owner；View 不直连 `AppDatabase`。
- 页面离场取消观察和写入任务，不让旧 scope 的结果覆盖新页面。
