# 书籍来源 - 需求文档

## 1. 目标

- 在“我的”中管理自定义来源与默认来源，支持新建、重命名、批量删除和分区内排序。
- 默认来源只允许排序/展示，不允许被误删或重命名。
- 删除来源时将关联书籍迁移到“未知来源”，避免悬空外键。

## 2. 规则

- 名称规范化后不能为空，不得与任何有效来源重名。
- 自定义来源和默认来源分别排序，禁止跨 scope 拖动。
- 批量删除、书籍来源迁移、来源软删除在单一事务完成。
- 删除成功以列表和书籍来源变化表达；失败保留原顺序并显示原因。

## 3. 验收

- 新建、重命名、批量删除和两个分区排序可用。
- 默认来源保护生效。
- 删除后书籍全部指向未知来源，不产生无效 source_id。
