## 2. 未对齐项结论

本次所有差异均为有证据的功能优化，不是设计倒退：

- 双阶段写入解决 iOS 文档冻结冲突。
- 先命中后加权解决无关模式填榜。
- 双指纹和独立上下文阻止单案例过度抽象。
- enforced 真实保护校验阻止状态虚标。
- Git warning 试运行解决 Android trailer 实际采用率为零时直接严格门禁的落地风险。

## 3. Android 反向优化建议

1. 搜索排序改为真实命中为准入条件，再增加 pattern 权重。
2. 为模式增加修复策略指纹和独立证据上下文校验。
3. active/enforced 分离用户批准与程序化保护，审计虚假 enforced。
4. 扩大评测到同义改写和边界负例，记录负例误召回率。
5. 在严格 trailer gate 前先统计实际采用率和误拦截成本。
