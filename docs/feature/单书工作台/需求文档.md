# 单书工作台 - 需求文档

## 1. 目标

- 以一本书为上下文统一承载目录、书摘、相关内容和书评，不再维护并行详情实现。
- 保留阅读计时、阅读详情、全屏编辑任务及返回现场。
- 搜索和目录筛选只影响页面展示；书摘、相关、书评排序写入 `sort` 表并跨重进恢复。
- 书摘、书评、相关内容继续遵循 Android `is_deleted` 软删除语义。

## 2. 核心流程

1. 进入书籍详情后，四个内容域常驻并保留各自滚动位置。
2. 目录可展开、收起、进入章节书摘或进入目录管理。
3. 书摘支持搜索、仅看有想法、查看、编辑、图片与 AI 链路。
4. 相关域支持分类筛选、普通内容编辑、相关书替换、占位书恢复和软删除。
5. 书评支持查看、新建、编辑、软删除；书籍评分使用统一评分 Sheet。
6. 每个域的排序由 `BookContentSortRule` 唯一表达并持久化。

## 3. 状态与反馈

- 首次读取使用 `LoadingGate` 延迟展示，写入立即禁用重复入口。
- 展示快照构建可取消，旧任务不得覆盖新搜索词或新数据库快照。
- 删除必须中心确认；失败保留当前页面并展示原因，成功通过列表变化表达。
- 页面离场取消观察、预处理、预热和写入任务。

## 4. 验收

- 目录/书摘/相关/书评切换、搜索和滚动位置稳定。
- 四种书摘排序、两种相关排序、两种书评排序可持久化。
- 章节、评分、关联书、书评和 AI/图片入口可达。
- 连续退出再进入不出现陈旧快照或双实现页面。
- 模拟器构建通过，不新增 Unit Test/UI Test。
