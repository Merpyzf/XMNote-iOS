# 书摘回顾 - 需求文档

## 1. 背景
- Android 已有“书摘回顾”页，用户可以按书籍、标签、排序规则回顾书摘，并通过卡片堆叠交互逐张切换。
- iOS 需要迁移该业务意图，同时使用原生 SwiftUI 页面结构、统一 Repository 边界和项目现有视觉组件。
- 本轮重点补齐卡片切换动效、后层卡内容预览、堆叠露出安全区、footer 封面比例与屏幕卡片宽度，避免卡片切换中途硬切和底卡露字。

## 2. 目标
- 在笔记 Tab 内提供“回顾”二级页，承载书摘回顾卡片流。
- 支持随机回顾和按书籍顺序回顾。
- 支持按书籍范围、标签范围、标签匹配规则筛选回顾内容。
- 卡片切换应连续、完整，不出现中途跳帧、硬切或状态突变。
- 后层卡片继续渲染正文和 footer 预览，但静止堆叠时露出的只能是纸面边缘、阴影和空白边距。
- footer 书籍封面必须使用 `XMBookCover`，保持全局封面宽高比；屏幕卡片封面维持紧凑宽度，不影响分享 PNG 版式。

## 3. 范围
- 笔记 Tab 二级切换入口：`笔记 / 回顾`。
- 回顾卡片主界面、设置 Sheet、标签编辑 Sheet、分享图入口、微信读书原文入口。
- 回顾卡组动效组件 `NoteReviewPagingDeck` 与纯动效规格 `NoteReviewPagingMotionSpec`。
- 屏幕回顾卡 `NoteReviewCardView`。
- 不包含“分享为图片”的固定 1240px 离屏渲染版式重设计。

## 4. 功能需求
1. 进入与加载
- 首次进入回顾页时加载本地设置、标签选项、已选书籍回显和第一页书摘。
- 首屏读取使用 `LoadingGate + LoadingStateView` 的延迟显示策略。
- 空数据时显示空态，并提供调整范围入口。

2. 卡片浏览
- 左滑进入下一张，右滑回到上一张。
- 接近当前已加载数据尾部时自动请求下一页。
- 点击当前卡片进入内容查看器，并保留当前回顾卡片顺序作为来源上下文。
- 横向卡片手势不能破坏卡片内部纵向滚动。

3. 设置与筛选
- 支持书籍范围多选；空选择代表全部书籍。
- 支持标签范围多选；空选择代表不限标签。
- 标签范围非空时支持“任一标签 / 全部标签”匹配规则。
- 支持“随机回顾 / 按书籍顺序”。
- 支持卡片配色与文本对齐设置；外观变化不应触发无意义的数据重载。

4. 卡片内容
- 卡片显示正文、想法、附图、标签、书籍封面、书名与作者。
- 书籍封面必须复用 `XMBookCover`。
- footer 不得出现额外灰色/深色横向块；保留顶部细分割线。
- 屏幕卡片 footer 封面宽度保持紧凑，宽高比由 `XMBookCover.aspectRatio` 统一推导。

5. 动效与堆叠
- 前景卡切换到后层必须是单一连续流程。
- 目标卡在层级 handoff 前后必须已经渲染正文和 footer，不允许空白纸面覆盖。
- 静止后层卡 `bodyOpacity/footerOpacity` 仍可见，但 `isReadable = false`，避免误触和 VoiceOver 读取后层内容。
- 后层卡露出量通过旋转后包围盒约束计算，侧边露出不得进入正文安全区，底部露出不得进入 footer 文本区域。

6. 操作菜单
- 支持查看详情、编辑标签、预览附图、分享为图片、打开微信读书原文。
- 已配置外部应用时支持发送到对应目标；发送过程需防重复触发并提供反馈。

## 5. 验收标准
- 前景卡切换到后方时动画完整连续，无中途硬切、跳帧或状态突变。
- 后层卡正常渲染正文和 footer，但静止堆叠露出区域不出现正文或 footer 文本。
- 前景卡宽度在 402pt 宽设备约为 354pt，保留当前阅读排版风格。
- footer 右侧不再出现深色/灰色横向像素块。
- footer 封面保持修改前紧凑宽度，并使用全局封面宽高比。
- 分享 PNG 仍保持独立固定版式，不受屏幕卡片宽度与 footer 封面调整影响。
- 编译通过当前已启动模拟器目标。

## 6. 风险与约束
- `zIndex` 层级切换与 `selection` 提交时机需要分阶段处理，否则动画尾段会切到新静止态。
- 后层卡内容可见与“不能露字”并不矛盾，必须通过几何约束控制露出范围，而不是回退为隐藏底卡内容。
- 卡片宽度、堆叠强度与封面尺寸属于屏幕卡片布局约束，不能误改分享图渲染器。
