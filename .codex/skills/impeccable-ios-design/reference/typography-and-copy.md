# Typography And Copy

## 目标

在 XMNote 现有文字系统内建立清晰、稳定的阅读层级，不追求 Web 海报感或人为制造的“标志性字体”。

## 规则

- 生产文本服从 `AppTypography` 或页面级组合 token；书架、书摘等已有专用 token 优先于通用样式。
- 系统字体是 iOS 原生基线，不是 AI 味。不要强制衬线字体、品牌字体、固定字号数量或任意字重来制造差异。
- 品牌字体只用于仓库规则已允许的品牌标题、关键数字或品牌强调位；正文和交互文案保持可读、可预测。
- 中文界面同时检查字重、动态行高、字面大小、截断和数字风格，不用英文字体搭配替代中文验证。
- 数值与单位拆层时保证读数速度：数字主导、单位退后，但保持亲密性和共同语义。
- 标题、说明、统计口径和操作文案靠近所属内容；用留白或分隔解释关系，不让相关信息视觉断开。
- 删除重复、空泛和界面已经表达的文案；按钮使用清晰动作，不用营销式形容词代替任务。
- 文本测量与渲染字体保持同源；涉及宽度、baseline、行高或跑马灯时复用对应 token 的测量字体。

## Token 边界

- 先复用现有 token。单个页面的局部差异默认局部组合，不直接新增全局文字样式。
- 只有至少两个独立场景存在相同语义、相同排版需求和相同修复模式时，才建议沉淀新 token。
- 若确需新增 token，说明目标场景、与现有 token 的差异及 Dynamic Type 行为。

## 反模式

- 为了去 AI 感强制衬线标题或品牌字体
- 为每个标题都配大图标
- 所有文字同样居中、同样字重、同样颜色
- 用随手 `.weight(...)` 或固定字号制造层级
- 为了“精致”把辅助文案做得过淡
